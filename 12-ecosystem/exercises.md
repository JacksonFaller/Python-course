# Exercises - Module 12

## Exercise 1 - Library evaluation

Choose a library for a real problem you have encountered. Compare it with a standard-library approach and record the trade-offs.

## Exercise 2 - Vertical slice

Build one thin end-to-end slice of your idea: input → processing → useful output.

## Exercise 3 - Review your architecture

Identify one abstraction you introduced only because it felt familiar from another language. Decide whether to keep or remove it.
