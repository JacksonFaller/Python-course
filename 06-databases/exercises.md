# Exercises - Module 06

Use `exercises/module06/` as the working implementation and `tests/module06/` as the feedback loop.

## Exercise 1 - Model

Complete the `Product` model and table mapping.

## Exercise 2 - Repository

Implement `add`, `get`, and `set_quantity`.

## Exercise 3 - Transaction behavior

Make the repository changes persist and verify them by opening a new session in the test.

## Exercise 4 - Domain boundary

Notice that the repository returns ORM objects. Decide whether that is acceptable for this small application or whether a domain model should sit between the ORM and business logic. Write down the trade-off.
