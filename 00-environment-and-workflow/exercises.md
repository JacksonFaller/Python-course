# Exercises - Module 00

These are workflow exercises rather than programming challenges. The runnable starter is in `../exercises/module00/`.

## Exercise 1 - Environment check

Open `../exercises/module00/environment_check.py` and complete the marked sections.

It should print Python version, interpreter path, current working directory, and whether `.venv` exists.

Run it directly with `python ../exercises/module00/environment_check.py`.

## Exercise 2 - Run as a module

Create a small `module-demo/app` package and run it with both `python app/main.py` and `python -m app.main`. Observe the import behavior and research why the invocation style can matter.

## Exercise 3 - Traceback practice

Introduce a deliberate error into one of your exercise programs. Read the traceback and identify the file, line number, exception type, and exception message before searching for the exact error online.
