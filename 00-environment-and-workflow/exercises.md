# Exercises - Module 00

## Exercise 1 - Environment check

Create `environment_check.py` as described in the lesson.

Expected output should contain four useful pieces of information, but the exact formatting is up to you.

## Exercise 2 - Run as a module

Create this structure:

```text
module-demo/
└── app/
    ├── __init__.py
    └── main.py
```

Make `main.py` print a message. Run it both ways:

```bash
python app/main.py
python -m app.main
```

Observe any difference in import behavior, then research why.

## Exercise 3 - Traceback practice

Introduce a deliberate error into your program. Read the traceback and identify:

- the file
- the line number
- the exception type
- the exception message

Do this without searching for the exact error first.
