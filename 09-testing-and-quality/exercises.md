# Exercises - Module 09

Use the existing project tests plus `exercises/module09/`.

## Exercise 1 - Parametrize

Convert repeated input/output validation cases into one parameterized test.

## Exercise 2 - Exceptions

Write tests for the exception behavior of a small parsing function.

## Exercise 3 - Mock an external dependency

Use `monkeypatch` to isolate a function from an HTTP dependency.

## Exercise 4 - Integration test

Exercise several API operations in a single scenario and assert the final state.

## Investigation

Run Ruff against the repository. Fix issues that affect correctness or maintainability, but don't blindly apply every suggestion without reading it.
